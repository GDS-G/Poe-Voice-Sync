Poe Voice Sync Privacy Policy

Effective date: August 5, 2026

1. Introduction

Poe Voice Sync reads Poe chatbot response text aloud using ElevenLabs or Hume. Paid access does not include a voice-provider account; users supply their own provider account and API key.

2. Information We Collect

  • Poe chatbot response text selected for speech, including automatically read new responses when enabled.
  • The selected voice provider, voice, volume, autoplay preference, and provider consent.
  • The user's ElevenLabs and/or Hume API key.
  • The license email, signed license token, license status, and limited PayPal subscription-reference metadata.

3. How We Use Your Information

When speech is requested, Poe Voice Sync sends only the text being read and required voice settings directly from the browser to the selected provider. The provider receives the user's API key to authenticate the request. These transfers are governed by the selected provider's terms and privacy policy.

4. Data Sharing

Poe Voice Sync does not send Poe message text or provider API keys to its developer, advertising networks, data brokers, or analytics services. It does not sell personal information or use it for advertising or unrelated profiling.

PayPal handles subscription checkout. A scheduled GitHub Actions workflow checks active subscriptions with PayPal and publishes short-lived signed entitlements through GitHub Pages. The public registry contains one-way license-email hashes and signed tokens—not raw emails, PayPal account details, subscription IDs, or API credentials.

5. Data Storage and Security

Provider API keys are stored in device-local extension storage and are not placed in browser sync storage. License identity and non-secret preferences may be stored in extension storage so settings and license state can be restored. Data remains until the user clears extension data or removes the extension, subject to the browser's storage behavior.

6. Your Choices

You have the right to:

  • Disable automatic reading or speech generation.
  • Choose either provider and replace or remove the provider API key.
  • Sign out, clear extension data, or uninstall the extension.

7. Third-Party Services

This extension interacts with the following third-party services:

  • ElevenLabs or Hume: Converts selected text to speech using the user's provider account.
  • PayPal: Used for secure payment processing.
  • GitHub Pages and GitHub Actions: Publishes and refreshes cryptographically signed subscription entitlements.

8. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated revision date.

9. Contact Us

Questions can be submitted through the Poe Voice Sync GitHub issue tracker.
